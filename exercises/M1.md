# M1 — Transaction search and pagination

**Planned for V0.2 · Mid-level · 15–20 minutes**

The V0.1 transaction endpoint lists all of one client's records ordered by transaction date then ID. No M1 starter variant or selectable test task is implemented yet.

Extend it with optional `fundId`, `investorId`, `transactionType`, `from`, `to`, `page`, and `size` filters. Combine filters using AND, make dates inclusive, reject reversed ranges with 400, preserve client scoping, and paginate in the database with deterministic sorting. Demonstrate combined filters, ties, empty results, and cross-client cases. Discuss index use and query cost. Evaluate JPA queries/Specifications, pagination, validation, and repository design.
